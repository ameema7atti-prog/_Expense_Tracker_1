# Expense Tracker Application 💰

An interactive and responsive Expense Tracker built using **React** for **Project 1** of the **Syntecxhub Web Development Internship**[cite: 32, 33]. This application allows users to monitor their income, track daily expenses, and view real-time balance updates in a simple and efficient dashboard[cite: 33].

## 🚀 Features
* **Form & State Management:** Built using React's `useState` hook to control user inputs and transaction lists dynamically[cite: 33].
* **Mock API Integration:** Uses `useEffect` to fetch and load sample expense records on initial render[cite: 33].
* **Input Focus:** Utilizes `useRef` to auto-focus form fields for an improved user experience[cite: 33].
* **Performance Optimization:** Employs `useMemo` and `useCallback` to optimize complex calculations and event handlers, preventing redundant re-renders[cite: 33].
* **Responsive Layout:** Clean, user-friendly UI designed to work across desktop and mobile screens[cite: 33].

## 🛠️ Tech Stack
* **Frontend:** React.js, JavaScript (ES6+), HTML5, CSS3[cite: 33]
* **Hooks Used:** `useState`, `useEffect`, `useRef`, `useMemo`, `useCallback`[cite: 33]
